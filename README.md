# augustoalt10.github.io

Link na bio do Augusto Oliveira — site estático (HTML, CSS e JS puros), publicado com GitHub Pages.

## Como atualizar

- **Seguidores:** edite os `data-count` em `index.html` (YouTube e TikTok). O total é somado automaticamente.
- **Links:** edite os `href` dos botões em `index.html`.
- **Foto:** troque `avatar.webp` (quadrada, ~400×400).

## Interações

Letras do nome pulam, botões inclinam e brilham, adesivos trocam ao clicar, a foto gira
(clique 5 vezes seguidas para o modo festa), os números recontam ao clicar e os rabiscos
do fundo seguem o mouse. Tudo respeita `prefers-reduced-motion`.
